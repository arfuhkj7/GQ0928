GAME PULSE 02 · 新游体验

NEW GAME TEST

《Fish Sort
Puzzle》

鱼类三消 × 鱼缸物理
一场有限槽位的动态整理。

点击气泡里的鱼，鱼会进入下方槽位；凑齐3条相同的鱼就自动消除。气泡里的鱼会滚动换位，每次拿走一条后，剩余鱼的位置都会变化。

Tile Match鱼缸物理槽位管理
06 / 13
《Fish Sort Puzzle: 三消益智遊戲》是一款鱼类主题加有限槽位三消加物理滚动的休闲益智游戏。玩法简单：点击气泡里的鱼进入下方槽位，凑齐3条相同的鱼自动消除；如果槽位被不同鱼塞满、无法继续三消就会失败。特色是气泡里的鱼会滚动换位，比普通 Tile Match 更动态。
GAME PULSE 02 · 新游体验

EXPERIENCE JUDGMENT

真正的策略，来自
“气泡滚动与槽位管理”。

01

核心操作

点击气泡中的鱼，鱼进入有限槽位，凑齐3条相同自动消除。

02

策略来源

气泡鱼滚动换位加有限槽位，优先凑“2+1”，避免槽位堆满不同鱼种。

03

动态反馈

三消特效、鱼群滚动换位、水族馆收集养成的持续目标感。

体验判断

比普通 Tile Match
更动态，每步都改变局面。

气泡里的鱼会滚动换位，每次拿走一条后剩余鱼的位置都会变化，槽位压力让错误顺序的代价被即时放大。

玩法构成

三消鱼缸物理槽位管理时间压力收集养成
07 / 13
核心策略是优先凑“2+1”完成三消，避免槽位同时堆太多不同鱼种。可以概括为：Tile Match 三消加鱼缸物理效果加槽位管理加时间压力加水族馆收集养成。和普通 Tile Match 最大的区别是气泡滚动让局面持续变化，不是静态匹配。
GAME PULSE 03 · 游戏资讯

GAME NEWS · MINECRAFT LIVE

《Minecraft》
全新维度 The Sift

14年来首个新维度第四大维度
2027 年加入

Mojang 在 Minecraft LIVE 正式公布全新维度 The Sift，将与主世界、下界和末地并列，成为游戏中的第四大维度，率先在《Minecraft Dungeons II》中登场。

08 / 13
在最新一期 Minecraft LIVE 上，Mojang 正式公布全新维度 The Sift。这是《Minecraft》超过14年来首次新增完整维度，未来将与主世界、下界和末地并列。The Sift 将率先在《Minecraft Dungeons II》中登场，玩家可通过世界中的神秘裂隙进入，并探索 Meadow、Carapace 等全新区域。官方确认该维度将在2027年加入 Java版和基岩版。
